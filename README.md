# TRACE

### Multimodal Fusion of Pathology Foundation-Model Embeddings and Genomics for Tumor Origin Prediction

TRACE is a multimodal machine learning framework for tumor tissue-of-origin prediction that integrates histopathology foundation-model representations with somatic genomic features.

The framework combines H&E whole-slide image embeddings with mutation, copy-number alteration (CNA), and SBS96 genomic features. Histopathology is modeled using multiple-instance learning (MIL), genomic data are modeled using XGBoost, and predictions from both modalities are integrated through stacked fusion. 

TRACE is developed using The Cancer Genome Atlas (TCGA) with site-stratified five-fold cross-validation and independently evaluated using the Clinical Proteomic Tumor Analysis Consortium (CPTAC).

## Overview

TRACE contains three primary modeling components:

### Genomics

An XGBoost classifier is trained on a fused patient-level genomic representation containing:

- Somatic mutation features
- Copy-number alteration (CNA) features
- SBS96 trinucleotide-context features

### Histopathology

H&E whole-slide images are represented using precomputed pathology foundation-model tile embeddings. These embeddings are modeled using:

- ABMIL
- CLAM
- TransMIL

### Multimodal Fusion

Patient-level genomic and histopathology predictions are aligned and integrated using late-fusion strategies including:

- Mean probability fusion
- Maximum probability fusion
- Probability multiplication
- Confidence-based voting
- Logistic-regression stacking

## Data

### Training Data

The Cancer Genome Atlas (TCGA)

The genomic representation integrates:

- Somatic mutation features
- Copy-number alteration (CNA) features
- SBS96 trinucleotide-context features

H&E whole-slide pathology is represented using precomputed pathology foundation-model tile embeddings.

Model development and evaluation use site-stratified five-fold cross-validation to prevent patients from the same collection site from appearing across multiple folds.

### External Validation

Clinical Proteomic Tumor Analysis Consortium (CPTAC)

CPTAC mutation, CNA, SBS96, and pathology embedding data are processed independently and aligned to the TCGA-trained feature space before external validation.

The trained TCGA genomic and histopathology classifiers are applied to CPTAC without retraining the primary models on the external-validation cohort.

## Models

### Genomic Classifier

The genomic branch uses XGBoost with nested hyperparameter optimization through Optuna.

The model integrates mutation, CNA, and SBS96 features and reports:

- Top-1 accuracy
- Top-3 accuracy
- Top-5 accuracy
- Weighted F1
- Macro F1

### Histopathology Classifier

The histopathology branch operates on precomputed H&E pathology foundation-model tile embeddings.

Supported multiple instance learning architectures include:

- ABMIL
- CLAM
- TransMIL

### Multimodal Fusion

TRACE supports several patient-level late-fusion strategies:

- Mean probability fusion
- Maximum probability fusion
- Probability multiplication
- Confidence-based voting
- Logistic-regression stacking

## Interpretability

### SHAP

SHapley Additive exPlanations (SHAP) are used to identify genomic features contributing to tumor-origin predictions.

Each patient's SHAP values are calculated using the model from the cross-validation fold in which that patient was held out, ensuring that explanations are generated by models that were not trained on the corresponding patients.

Tumor-origin-specific genomic drivers are summarized using normalized waterfall plots.

### Ablation Study

Genomic modality ablation evaluates the effect of removing:

- Somatic mutations
- CNA
- SBS96
- Somatic mutations + CNA
- Somatic mutations + SBS96
- CNA + SBS96

Performance changes are evaluated relative to the complete genomic model.
